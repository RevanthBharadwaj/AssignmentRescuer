# Paper format

The student's papers follow APA 7 student paper format. This file records the exact layout, taken from one of the student's own submitted papers (only the formatting was read; no content is stored in this repository). The writing and export milestone must produce documents that match it.

## Page

| Setting | Value |
|---|---|
| Paper size | US Letter, 8.5 × 11 in |
| Margins | 1 in on all sides |
| Font | Times New Roman, 12 pt, everywhere (headings included) |
| Line spacing | Double (2.0) throughout, no extra space before or after paragraphs |
| Paragraph indent | 0.5 in first line for body paragraphs |
| Header | Page number, top right, on every page including the title page |
| Running head | None (student paper) |
| Footer | Empty |

## Order of pages

1. Title page
2. Abstract (new page)
3. Body (new page), starting with the paper title repeated, centred and bold
4. References (new page)

## Title page

Centred, double spaced, one item per line, no blank line between items:

1. Paper title, **bold**
2. Student name
3. University
4. Course as `CODE: Course name`, with the code hyphenated (for example `BUS-610: Strategic Management`)
5. Instructor (for example `Dr. Jane Doe`)
6. Due date written out (for example `November 7, 2026`)

The app fills items 2 to 6 from Semester setup (your name, university), the course (code, name, instructor) and the assignment's due date. The title is typed per assignment.

## Abstract

`Abstract` centred and bold on its own line. One paragraph with no first line indent. Then a `Keywords:` line, indented, with the label in italics followed by the keywords in plain text.

Note for the export milestone: in the sample the `Keywords:` label was not italic. APA 7 italicises it, so export should italicise the label and the review tools can point it out.

## Headings

| Level | Format |
|---|---|
| Paper title (top of body) | Centred, bold |
| Level 1 | Centred, bold, title case |
| Level 2 | Flush left, bold, title case (style present, not used in the sample) |

## References

`References` centred and bold on a new page. Entries in alphabetical order, double spaced, with a 0.5 in hanging indent. DOIs and URLs written as full links.
